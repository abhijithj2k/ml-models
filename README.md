# Machine Learning Fundamentals

Early machine-learning notebooks using scikit-learn.

| Notebook | What it does |
|---|---|
| `restaurant_review_sentiment.ipynb` | Classifies restaurant reviews as positive or negative. Compares SVM and Naive Bayes models on bag-of-words features, saves the pipeline with joblib and serves predictions through a Streamlit app. |
| `startup_profit_regression.ipynb` | Predicts startup profit from spending data with linear regression (R² 0.94), with exploratory plots and model serialisation. |
| `simple_linear_regression.ipynb` | Simple linear regression walkthrough. |
| `multiple_linear_regression.ipynb` | Multiple linear regression walkthrough. |
| `polynomial_regression.ipynb` | Polynomial regression walkthrough. |
| `data_preprocessing.ipynb` | Missing values, encoding, scaling and train/test splitting. |

## Tools

Python, scikit-learn, pandas, NumPy, Matplotlib, seaborn, Streamlit.
